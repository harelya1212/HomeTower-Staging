# HomeTower - Staging

Household Financial Control Tower: a family-collaborative app for a household's future financial situation.

- This repo is STAGING. It mirrors the future live product plus unreleased development.
- Live will live in a separate repo and stays frozen until an explicit promotion order from the product owner.
- Status: Phase 0 - foundation package only (vision, process rules, Phase 1 spec, brand assets). No application code yet.

## Documents
- `VISION.md` - the product vision, in the owner's wording
- `PROCESS.md` - binding build rules (token optimization, staging/live, one asset library, QA gates)
- `PHASE1.md` - Phase 1 scope, deferred list, success gate
- `assets/` - the single asset library; every asset is registered in `assets/ASSETS.md`

## Name and logo
HomeTower. Logo: a house that is also a control tower; the tower's radar arc doubles as a rising chart line. One deep color, no mascot. See `assets/ASSETS.md`.
