# HomeTower app

Phase 1E. Layout:

- `engine/` - TypeScript port of the Python reference engine
  (../engine/hometower_engine). Same modules, same semantics.
- `packs/` - the content packs, shared verbatim with the Python engine
  (../engine/content). Tax data is content with a version, never code.
- `engine-tests/` - cross-language golden vectors: vectors.json was
  generated by the Python engine; run.ts executes the TypeScript engine
  against it. Any drift fails the run.

Engine tests (no dependencies, Node >= 22):

    node engine-tests/run.ts

The Expo shell (screens, navigation, on-device OCR) is built on top of
this engine in Phase 1E steps 2-5 - see ../SHELL_DESIGN.md.
